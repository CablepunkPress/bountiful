# Custom

This folder is for extending Bountiful with your own hardware profile and your own tool groups. Updates never change what you put here.

- `profile/` holds one hardware profile of your own. If a profile is here, the setup uses it instead of Bountiful's.
- `tools/` holds your own tool groups, one folder each. Add one to an agent with `bountiful add GROUP ID`.

How to write a profile and a tool group is explained in Bountiful's technical guide.
